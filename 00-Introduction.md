# Phase 0 - Introduction


Welcome to DevOps Zero To One 🚀


Imagine you created a simple Python file:


```python
print("Hello DevOps")
```


This works on your laptop.


But companies have bigger problems:


- Thousands of developers
- Millions of users
- Multiple releases everyday


Questions:


How do we manage code?

How do we test safely?

How do we deploy automatically?

How do we recover from failures?



DevOps solves these problems.

Docker

Bazel

Creates reliable builds



JFrog

Stores releases



AWS

Runs and stores applications



Temporal

Manages long running workflows
